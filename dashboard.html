AIAI 전체 현황 해석

✅조작점검 — 책임 수준 (MCR)

확인 내용: 고책임 그룹(그룹1·2)이 저책임 그룹(그룹3·4)보다 MCR 점수가 유의하게 높은지 검증합니다.
판정 기준: t-검정 p < .05, 고책임 평균 > 저책임 평균 → ✅ 조작 성공

✅조작점검 — 설명 수준 (MCE)

확인 내용: 설명높음 그룹(그룹1·3)이 설명낮음 그룹(그룹2·4)보다 MCE 점수가 유의하게 높은지 검증합니다.
판정 기준: t-검정 p < .05, 설명높음 평균 > 설명낮음 평균 → ✅ 조작 성공

불성실 응답자 비율이 높으면 데이터 정제 후 재분석을 권장합니다.

🧪2×2 이원분산분석 (Two-way ANOVA)
