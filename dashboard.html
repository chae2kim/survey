AIAI 전체 현황 해석

✅조작점검 — 책임 수준 (MCR)

확인 내용: 고책임 그룹(그룹1·2)이 저책임 그룹(그룹3·4)보다 MCR 점수가 유의하게 높은지 검증합니다.
판정 기준: t-검정 p < .05, 고책임 평균 > 저책임 평균 → ✅ 조작 성공

✅조작점검 — 설명 수준 (MCE)

확인 내용: 설명높음 그룹(그룹1·3)이 설명낮음 그룹(그룹2·4)보다 MCE 점수가 유의하게 높은지 검증합니다.
판정 기준: t-검정 p < .05, 설명높음 평균 > 설명낮음 평균 → ✅ 조작 성공

👁IMC (주의력 확인)

기준: IMC=1 선택 → ✅ 통과 / 그 외 → ❌ 불성실 응답자
불성실 응답자 비율이 높으면 데이터 정제 후 재분석을 권장합니다.

AIAI 조작점검 해석

α신뢰도 (Cronbach's α)

기준: α ≥ 0.8 ✅✅ 우수 · α ≥ 0.7 ✅ 양호 · α < 0.7 ⚠️ 검토 필요

✓타당도 (AVE · CR)

AVE ≥ 0.5 → 수렴타당도 확보 · CR ≥ 0.7 → 합성신뢰도 양호

⚖판별타당도 (HTMT 비율)

HTMT < 0.85 → 보수적 기준 ✅ · HTMT < 0.90 → 자유 기준 ✅ · 그 이상 ⚠️ (Henseler et al., 2015)

🧪2×2 이원분산분석 (Two-way ANOVA)

주효과 A: 책임 수준(고/저)이 종속변수에 미치는 영향
주효과 B: 설명 수준(높음/낮음)이 종속변수에 미치는 영향
상호작용 A×B: 책임 수준에 따라 설명 수준 효과가 달라지는지 ← 핵심!
